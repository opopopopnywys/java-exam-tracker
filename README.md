# java-exam-tracker

**在线演示**：https://opopopopnywys.github.io/java-exam-tracker/

一个为计算机二级 Java 备考做的「复习排程 + 错题管理」单页应用。零依赖、零框架、纯前端，整站 96KB。

## 解决了什么问题

备考过程中有两个纯手工的负担：

1. **算复习日期**：按间隔重复曲线安排重做节点，靠脑子记或日历手填，容易漏
2. **找错题截图**：题做错了截图扔在相册里，堆到几十张之后基本不会再看

这个工具把这两件事自动化：录入一次学习记录，自动排出 D+2 / D+4 两个重做节点并汇总成日历；错题截图 Ctrl+V 直接粘贴，压缩后存入浏览器本地，按章节、错因、重做状态归档筛选。

## 功能

**复习日历**

- 录入「日期 + 章节 + 掌握度」，自动生成 D+2、D+4 重做节点
- 今日待复习清单（只显示到期且未完成的）
- 未来 15 天复习负载日历，一眼看出哪天排太满
- 章节掌握度五级色标（灰 → 蓝 → 绿 → 黄 → 红）

**错题本**

- 三种方式录入截图：Ctrl+V 粘贴 / 拖拽 / 点击选择文件
- 错因四分类：概念盲区 / 语法细节 / 审题错误 / 环境操作
- 章节 × 错因 × 重做状态 三维组合筛选
- 重做追踪：重做对了 / 重做错了 / 删除
- 统计卡片：总数、未重做、已重做✓、已重做✗

**调试页**

- `debug.html`：直接读取底层存储，用于排查本地数据异常

## 技术要点

| 要点 | 实现 |
|---|---|
| 存储分层 | 结构化文字存 localStorage，图片存 IndexedDB（keyPath 索引 by id） |
| 图片压缩 | canvas 等比缩放至最大边 1000px + 质量 0.7 后转 base64 |
| 模块划分 | IIFE 封装成 4 个独立模块：`storage` / `review` / `mistakes` / `app` |
| 依赖管理 | 无框架、无第三方库，脚本按固定顺序串行动态注入 |
| 状态自省 | 常驻状态条实时显示三类数据的条数，便于确认写入是否成功 |
| 缓存处理 | 脚本与样式带 `?t=时间戳`，避免开发期浏览器缓存导致改了不生效 |

代码量约 2300 行（其中 JS 约 1200 行），无构建步骤。


## 本地运行

**不要直接双击 `index.html`。** `file://` 协议下浏览器对 IndexedDB 有限制（Firefox 直接禁用，Chrome 视版本而定），错题截图会存不进去。

用本地 HTTP 服务打开：

```bash
python -m http.server 8090
# 浏览器访问 http://localhost:8090/index.html
```

Windows 下也可直接双击 `启动服务器.bat`。

## 数据说明

所有数据（学习记录、错题、截图）**只保存在你自己的浏览器里，不上传任何服务器**。

这是设计取舍，不是 bug：

- 隐私上是优点——没有账号、没有服务端、数据不出本机
- 代价是换设备 / 换浏览器不同步，清除浏览器数据会丢失
